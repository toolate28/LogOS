## A. Mathematical core

### Coadjoint orbit

For a Lie group \(G\), Lie algebra \(\mathfrak{g}\), and \(\mu \in \mathfrak{g}^*\), the coadjoint orbit is

\[
\mathcal{O}_\mu = \{ \operatorname{Ad}^*_g \mu : g \in G \}.
\]

Tangent vectors at \(\mu\) are generated by elements \(\xi, \eta \in \mathfrak{g}\):

\[
v_\xi = \operatorname{ad}^*_\xi \mu, \qquad
v_\eta = \operatorname{ad}^*_\eta \mu.
\]

### KKS form

Up to sign convention, the KKS symplectic form is

\[
\Omega_\mu(v_\xi, v_\eta) = \langle \mu, [\xi, \eta] \rangle.
\]

This gives each coadjoint orbit a symplectic structure. A Hamiltonian \(H\) determines a vector field \(X_H\), hence an **admissible evolution policy**.

### Correction (do not restate the wrong obstruction)

The general theory already supplies a canonical symplectic form on coadjoint orbits. The LogOS obstruction is **not** “KKS theory is missing.” It is:

> **No explicit, computationally tractable KKS realization has yet been selected for the relevant product-state orbit.**

That is an **implementation and modelling** obstruction.

## B. Mathematical design language → product architecture

| Geometry | Product architecture |
|----------|----------------------|
| Lie group \(G\) | Permitted transformation family |
| Lie algebra \(\mathfrak{g}\) | Infinitesimal commands or actions |
| Coadjoint orbit \(\mathcal{O}_\mu\) | Valid state manifold |
| Orbit type / singular stratum | Product mode |
| Hamiltonian \(H\) | Objective, cost, or operating preference |
| Hamiltonian flow | Runtime transition policy |
| KKS form \(\Omega\) | Compatibility law between actions |
| Moment map \(J\) | Symmetry-aware telemetry or resource exposure |
| Casimir \(C\) | Quantity constant across every allowed flow |
| Symplectic reduction | Remove redundant degrees of freedom |
| Symplectic integrator | State update that limits structural drift |

### Modes are orbit types, not painted regions

A regular coadjoint orbit is already one symplectic leaf. Product **modes** should be represented by:

- different orbit types, or  
- different leaves, or  
- singular strata  

—not by arbitrary regions painted inside one orbit.

### Categorical separation (load-bearing)

Moment maps and Casimirs do **different jobs**:

| Object | Job | Must satisfy |
|--------|-----|--------------|
| **Moment map** \(J\) | Records conserved / controlled quantity for a symmetry | Equivariance under the claimed group action (when asserted) |
| **Casimir** \(C\) | Poisson-centre observable | \(\{C, f\} = 0\) for every observable \(f\) |

**Category C conventions are not free Casimirs.**

The following remain **Category C** unless LogOS defines (1) Poisson state space, (2) bracket, (3) group action, (4) moment map, and (5) proof or test of flow-invariance:

- \(\alpha + \omega = 15\)
- WAVE thresholds
- category ceilings (A/B/C/D)
- strand weights \(8/5/3\)

That separation prevents KKS from becoming mathematical gold leaf over existing policy constants.

## C. Minimal shippable object — Orbit Policy Kernel

The smallest useful product primitive is **not** “a coadjoint orbit UI.”  
It is an **Orbit Policy Kernel** (OPK):

```yaml
orbit_policy:
  id: handoff-coherence-v0

  algebra:
    basis: [build, verify, hold, quarantine]
    structure_constants: path/to/bracket.json

  state:
    coordinates:
      - freshness
      - authority
      - uncertainty
      - tool_availability
      - provenance_completeness

  orbit:
    seed: path/to/reference-state.json
    action: coadjoint

  dynamics:
    hamiltonian: path/to/handoff-cost.wasm   # or pure function for v0
    integrator: implicit-midpoint
    step_limit: 0.05

  declared_invariants:          # software rules — enforced, not “math”
    - mark_id_immutable
    - category_ceiling_nonincreasing
    - builder_not_verifier

  candidate_casimirs:           # must earn the label
    - provenance_class
    - authority_separation

  moment_map:
    outputs:
      - active_authority
      - resource_exposure
      - verification_debt

  reduction:
    quotient_by:
      - presentation_style
      - client_specific_metadata

  telemetry:
    emit_atom_receipt: true
    emit_mark_spine: true
```

**Deliberate split:**

- `declared_invariants` → enforced software rules (Category B/C process)  
- `candidate_casimirs` → must earn mathematical status under §E validation  

### Tiny runtime surface (enough to ship)

```text
classify(state)           -> orbit / mode
admissible(state, action) -> bool + reason
step(state, action, dt)   -> next state
reduce(state)             -> canonical representative
observe(state)            -> moment-map telemetry
verify(trace)             -> invariant and drift report
receipt(trace)            -> ATOM / Marked Stream spine
```

That is the entire shippable mathematical object for v0.

## D.1 First worked instance — Marked Stream handoff modes

This section is the **v0 Orbit Policy Kernel instance**. Everything below must map to an observable software quantity.

### D.1.1 Lie algebra \(\mathfrak{g}\) (explicit)

**Basis** (infinitesimal commands / roles in the algebra, not UI labels):

\[
e_B = \texttt{build}, \quad
e_V = \texttt{verify}, \quad
e_H = \texttt{hold}, \quad
e_Q = \texttt{quarantine}
\]

**Structure constants (v0 proposal — Category B until Jacobi tests exist):**

Interpret bracket as “who can revise whom / who blocks whom.” Antisymmetric by definition: \([x,y] = -[y,x]\), \([x,x]=0\).

| \([\, ,\, ]\) | \(e_B\) | \(e_V\) | \(e_H\) | \(e_Q\) |
|---------------|---------|---------|---------|---------|
| \(e_B\) | \(0\) | \(e_H\) | \(e_B\) | \(e_Q\) |
| \(e_V\) | \(-e_H\) | \(0\) | \(e_V\) | \(e_Q\) |
| \(e_H\) | \(-e_B\) | \(-e_V\) | \(0\) | \(e_Q\) |
| \(e_Q\) | \(-e_Q\) | \(-e_Q\) | \(-e_Q\) | \(0\) |

**Product reading (not free poetry):**

| Bracket | Software meaning |
|---------|------------------|
| \([e_B, e_V] = e_H\) | Simultaneous BUILD and VERIFY without resolution → **HELD** (authority seam) |
| \([e_B, e_H] = e_B\) | Hold does not erase build intent; re-enter BUILD when hold lifts |
| \([e_V, e_H] = e_V\) | Same for VERIFY |
| \([e_Q, \cdot] = \pm e_Q\) | Quarantine absorbs other generators — isolation mode |

**JSON path (to materialize):** `docs/componentry/kks/bracket-handoff-v0.json`  
Until that file exists, the table above is the structure-constant SoT for this worked instance.

**Jacobi status:** **unproven** — must be tested numerically (§E.2) before any “live KKS” claim.

### D.1.3 Orbit / modes

**Seed orbit** = Marked Stream state for a single `mark_id` (and its BUILD claim tree).

| Mode (orbit type / stratum) | Meaning |
|-----------------------------|---------|
| `BUILD` | Builder owns emits; may assert categories; never self-countersign |
| `VERIFY` | Verifier surveys; may countersign; never mints new Mark-Id |
| `HELD` | Authority seam or unresolved D-fire; no promote |
| `QUARANTINED` | Key leak (D5), label mutation (D2), or untrusted origin |
| `RELEASED` | Countersigned + D6/D7 green on claimed artifacts |

Modes are **strata of the product-state orbit**, not painted regions inside one leaf.

### D.1.4 Actions (admissible generators / finite moves)

| Action | Algebra colour | Effect on mode (intended) |
|--------|----------------|---------------------------|
| `emit` | build | mint Mark-Id + BUILD trailers + ledger row |
| `countersign` | verify | add VERIFY trailers + cert head; never new Mark-Id |
| `re-snapshot` | build/verify | refresh survey or claim tree after merge |
| `reconcile` | hold→resolve | clear ahead/behind or D7 drift by re-mint or re-survey |
| `promote` | release path | BUILD→VERIFY handoff only if admissible |
| `quarantine` | quarantine | force QUARANTINED on D2/D5/key presence |

`admissible(state, action)` must return **bool + reason** using declared invariants and detector state.

### D.1.5 Hamiltonian (cost / operating preference)

v0 cost (pure function; WASM later optional):

\[
H =
w_d \cdot \texttt{verification\_debt}
+ w_s \cdot \texttt{stale\_state\_penalty}
+ w_a \cdot \texttt{authority\_seam\_penalty}
+ w_p \cdot \texttt{provenance\_discontinuity}
\]

| Term | Observable proxy |
|------|------------------|
| verification debt | marks without countersign (D1 coarse) |
| stale-state penalty | D7 fire or unreconciled ahead/behind |
| authority-seam penalty | BUILD claims with `self_certified: true` or role confusion |
| provenance discontinuity | missing trailer fields; cert_sha256 null after VERIFY claim |

Weights \(w_*\): software policy (Category C until calibrated). They are **not** Casimirs.

**Integrator (v0):** discrete mode machine with `step_limit` semantics — at most one mode hop per receipted action; no silent multi-hop.

Preferred structure-preserving stepper later: **implicit midpoint** vs ordinary Euler (§E.7). For discrete modes, “midpoint” ≈ require dual observation (BUILD claim + VERIFY survey) before RELEASED.
