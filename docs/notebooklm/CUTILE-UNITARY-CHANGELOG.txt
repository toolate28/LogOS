5. EXISTENCECERTIFICATE E2E
---------------------------
Emit (Rust):
  cargo run --bin demo_existence_certificate_emission
  → existence_certificate.json (BLAKE3 self-hash, camelCase JSON)

Validate (Python):
  python scripts/demo_bridge_to_lean.py
  → existence_certificate.validated.json

Consume (Lean):
  cd lean && lake build K22.Existence
  K22.Existence.fromExistenceCertificate → TomczakExistence
  Trust: caller Bool=true; gate construction verified in Lean
