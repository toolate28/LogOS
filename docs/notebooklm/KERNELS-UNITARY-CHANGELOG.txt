3. R-MATRIX CONTRACT (r_matrix_interface.h)
-------------------------------------------
Cascade layer: unified kernel interface (L11)

Structural identity across Rust / CUDA / WGSL / Python:
  R = diag-block form with entries q, 1/q, and off-diagonal (1 - q²)
  Layout: row-major 4×4 over complex doubles (re, im interleaved or paired)

Types:
  typedef struct RMatrixC64 {
    double re_im[32];  /* 16 complex pairs → 32 doubles, flattened row-major */
  } RMatrixC64;

API:
  int fundamental_r_matrix_host(double q, RMatrixC64* out);
  /* 0 success; non-zero if q invalid (e.g. q == 0) */
  /* GPU kernels in fundamental_r_matrix.cu share the same algebra */

4. BLACKWELL KERNEL FAMILY
--------------------------

used elsewhere in cutile PTX scripts).

  blackwell-fft.cu      — spectral transforms supporting lattice analysis
  blackwell-pcr.cu      — PCR-related compute path
  blackwell-rips.cu     — topological data analysis (rips) acceleration path

These are host-repo “fundamental” kernels; cutile may ship versioned variants
(e.g. blackwell_entropy_v2.cu) for crate-local backends.
