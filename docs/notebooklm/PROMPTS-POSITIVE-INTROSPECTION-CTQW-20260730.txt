0. HOW TO RUN A POSITIVE INTROSPECTION LOOP
------------------------------------------
A loop is one walk on a graph of claims, not a monologue.

  Graph G = (V, E)
    V = claims, files, tools, blockers, feelings-of-certainty
    E = evidence links, call edges, contradiction edges, handoff edges

  Continuous-time quantum walk (CTQW) metaphor (Category B for agents):
    Hamiltonian H ~ graph Laplacian (or signed Laplacian of trust/evidence)
    State |ψ(t)⟩ evolves; observables:
      · Return probability  P_return(t)  — “do we keep landing on the same claim?”
      · Participation ratio PR(t)         — “is attention localized or delocalized?”
      · Hitting / cover time proxy       — “how long to honest gap vs false green?”

  Positive loop (TEMET NOSCE):
    1 OBSERVE   — state vertices (HAVE)
    2 SUPERPOSE — hold competing tags A/B/C/D without collapse
    3 INTERFERE — cancel false greens; reinforce evidenced paths
    4 MEASURE   — force HAVE / NEED / CASCADE-BLOCKER output
    5 RESET     — one next step only; conserve music (don’t thrash)

  Exit condition: one cascade-blocker named + one next primitive + Category tag.
  Fail condition: re-promoting demoted claims; inventing live tools; Steiner closed.
